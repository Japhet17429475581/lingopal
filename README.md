# LingoPal

Испанский маленькими шагами: карточки, личный словарь, интервальное повторение, грамматика и чтение. Приложение работает как Telegram Mini App; для разработки есть отдельный локальный режим.

## Быстрый запуск на Windows

Нужен Python 3.11 или новее. Открой PowerShell в папке проекта:

```powershell
powershell -ExecutionPolicy Bypass -File .\start-local.ps1
```

Скрипт создаст `.venv`, установит зависимости и запустит приложение на **http://127.0.0.1:3000**. При повторном запуске зависимости устанавливаются только при изменении `requirements.txt`. Остановка — Ctrl+C.

Локальный режим использует тестового пользователя с ID 1. Карточки, грамматика, словарь, чтение и прогресс работают без токенов. Для ответов Хосе, новых переводов и озвучки нужно подключение к соответствующим внешним сервисам. Переводы уже известных базе слов работают без AI.

## Запуск вручную

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
.\.venv\Scripts\python.exe run.py
```

База SQLite `spanish.db` создаётся автоматически. Контент импортируется при запуске через `run.py` и через `uvicorn src.api:app`. Повторный импорт грамматики обновляет существующие записи по стабильным ID и сохраняет результаты пользователей. Не удаляй базу для обновления контента. Перед переносом существующей базы сделай её резервную копию.

## Telegram и хостинг

В `.env` или переменных окружения хостинга укажи:

```dotenv
ALLOW_DEV_AUTH=false
HOST=0.0.0.0
PORT=3000
BOT_TOKEN=токен_из_BotFather
MINI_APP_URL=https://адрес-твоего-приложения/
DEEPSEEK_API_KEY=твой_ключ
DEEPSEEK_MODEL=deepseek-flash
# DATABASE_URL=sqlite:////app/data/spanish.db
```

После этого запусти `python run.py`. Он запустит API, Telegram polling и планировщик уведомлений; при завершении закроет их вместе. Для polling запускай один экземпляр `run.py`. Можно запускать только API: `uvicorn src.api:app --host 0.0.0.0 --port 3000`.

Проверка Telegram использует подписанный `Telegram.WebApp.initData`, срок действия и сопоставление ID запроса с проверенным пользователем по [документации Telegram](https://core.telegram.org/bots/webapps#validating-data-received-via-the-mini-app). Параметр `?tg_id=` больше не даёт доступа к чужому профилю. Локальный вход требует `ALLOW_DEV_AUTH=true` и подключение с loopback-адреса; на хостинге оставляй его выключенным.

Модель Хосе задаётся переменной `DEEPSEEK_MODEL`; имя по умолчанию сверено с [документацией DeepSeek](https://api-docs.deepseek.com/). Отсутствие ключа не мешает запуску остальных разделов. Ошибки внешнего сервиса отображаются без раскрытия внутренних исключений. Запросы к AI, переводу и озвучке ограничены суммарно 30 запросами в минуту на пользователя в одном процессе.

Для Docker подключи постоянный том к файлу базы и каталогам `web/static/audio` и `web/static/shares`, если нужны долговечные файлы. Health check: `GET /api/health`. Референсная и проверенная конфигурация — SQLite; PostgreSQL в этой среде не проверялся. Планировщик и учебные дни пока используют UTC для всех пользователей.

## Грамматика

- 24 последовательных блока на уровнях A1, A2, B1 и B2.
- 72 коротких урока: правило, примеры, типичная ошибка.
- 144 упражнения: выбор ответа, верно/неверно и сборка фразы.
- В конструкторе слова можно возвращать обратно до отправки ответа.
- Правильные ответы находятся на сервере; клиент получает объяснение после ответа.
- Для прохождения нужно минимум 80%. Следующий блок открывается сервером.
- Опыт выдаётся за улучшение лучшего результата и за первое прохождение; повторный запрос не начисляет опыт снова.
- История попыток, лучший результат и завершённые темы сохраняются в базе.

Исходный материал редактируется в `scripts/build_grammar_content.py`. После правок:

```powershell
python scripts/build_grammar_content.py
.\.venv\Scripts\python.exe -m scripts.import_grammar
```

Режим предложений содержит 48 отдельных карточек, по 12 на уровень; они хранятся в `data/sentences.csv`.

## Проверки

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -q
```

Для браузерной проверки сначала запусти локальный сервер, затем:

```powershell
.\.venv\Scripts\python.exe tests/browser_smoke.py
```

Браузерный сценарий использует установленный Google Chrome. Для Edge: `$env:BROWSER_CHANNEL='msedge'`. Проверяются размеры 1440, 390 и 320 px, карточки, словарь, полный тест грамматики, читалка, профиль и темы. Скриншоты сохраняются в `artifacts/`. Сценарий меняет прогресс локального тестового пользователя; запускай его на базе для разработки.

Автотесты API работают на отдельной временной базе и проверяют подпись и срок Telegram-сессии, запрет доступа к чужим данным, блокировку тем, серверную проверку ответов, повторную отправку, награды, импорт с сохранением прогресса, карточки, интервальное повторение, перевод из кэша и прогресс чтения. Реальные запросы к Telegram, DeepSeek и TTS в этих тестах не выполняются.
